# Validación HITL — Planificación MVP2

## Decisión del equipo

El equipo decidió incorporar **cinco historias nuevas (HU13–HU17)**, independientes de las doce historias originales y **complementarias** a sus funcionalidades. Se descartó reescribir las HU01–HU12 para incluir voz dentro de cada una.

## Revisión humana

| Aspecto | Decisión |
|---|---|
| Número de historias | Cinco HU nuevas: dictado de campos, creación de tareas, informes, asignación y lectura. |
| Relación con MVP1 | HU13–HU17 amplían funcionalidades existentes, sin sustituir sus criterios originales. |
| Organización | Cada HU se conserva por separado para facilitar priorización, implementación, pruebas y trazabilidad. |
| Estimaciones | Las prioridades y Story Points propuestos requieren confirmación del equipo y cotejo con Jira. |
