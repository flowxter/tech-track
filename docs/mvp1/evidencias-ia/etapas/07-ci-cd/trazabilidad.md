# Trazabilidad — CI/CD

| Elemento | Evidencia disponible | Situación |
|---|---|---|
| Scripts locales de compilación | `front/package.json`, `back/package.json` | Compilaciones ejecutadas en etapa 06 |
| Pruebas unitarias | `back/package.json`, informe fase 1 | Seis aprobadas localmente |
| Control de versiones | GitHub, repositorio de TechTrack | Repositorio conocido; no prueba ejecución automatizada |
| Workflow de integración continua | Configuración y runs de GitHub Actions u otra herramienta | **No acreditado** en el material aportado |
| Despliegue de aplicación | URL, logs y prueba de humo | **No acreditado** en el material aportado |

No afirmar que compilación local equivale a CI/CD. El archivo `docs/08-despliegue.md` debe contrastarse con evidencia real antes de declarar esta etapa terminada.
